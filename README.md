# 🧠 Memory Card Game 🎴

A fun and interactive **Memory Card Matching Game** built using **HTML, CSS, and JavaScript**.
Test your memory skills by matching all the card pairs in the least number of moves! 🚀

---

## 🎮 How to Play

* Flip two cards at a time
* If they match ✅ → they stay open
* If they don’t ❌ → they flip back
* Match all pairs to win the game 🏆

---

## ✨ Features

* 🎴 Smooth card flip animations
* 🧠 Improves memory skills
* ⏱️ Move-based gameplay
* 💻 Simple and clean UI
* 📱 Beginner-friendly project
